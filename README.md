\# Простые алгоритмы сортировки



Учебный проект по алгоритмам и структурам данных.



\## Что реализовано



1\. \*\*Сортировка пузырьком\*\* — `bubble\_sort(arr)`.

2\. \*\*Сортировка выбором\*\* — `selection\_sort(arr)`.

3\. \*\*Сортировка вставками\*\* — `insertion\_sort(arr)` (для сравнения).

4\. \*\*Сравнение скоростей\*\* — для размеров 100, 500, 1000, 2000, 5000.

5\. \*\*График\*\* зависимости времени от размера списка.



\## Анализ сложности



Все три алгоритма имеют \*\*временную сложность O(n²)\*\* в среднем и худшем случаях. 



\- \*\*Пузырьком:\*\* много обменов, но есть оптимизация — если массив уже отсортирован, выходит за O(n).

\- \*\*Выбором:\*\* всегда O(n²), но меньше обменов, чем у пузырька.

\- \*\*Вставками:\*\* эффективен для почти отсортированных данных.



\*\*Пространственная сложность:\*\* O(1) — сортировка на месте.
